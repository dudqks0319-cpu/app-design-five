
Resolve mixed choices into concrete rules, for example: use option 1's bottom navigation and list hierarchy, option 4's restrained palette, and the user's larger type request. Keep the shared product requirements even if a concept image omits or distorts them.

Treat generated text as a visual hint until checked against the exact copy. Use fictional sample data. Do not transmit existing private app content or personal screenshots merely to reproduce their layout.

## Resume record

Keep only the task's useful restart facts in its local ledger: stage reached, image locations, user selection, readable brief, design project/run references when needed, exact blocker and next authorized action. A running job must be inspected before starting another. Do not place private run records, prompts with personal data or account identifiers in the distributable skill.
